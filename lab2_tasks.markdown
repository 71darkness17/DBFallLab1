### Постановка задачи:
* Написать запрос на языке sql, который будет решать поставленную задачу.
* Кратко пояснить словами, что делали и какие конструкции использовали.

### Примечание:
* Подходите к задаче как аналитик, те информация должна осмысленной и следовать какой-то логике, если ее будет сложно проследить, то придется ответить на доп вопросы.
* В результатах работы запросов должно быть максимально кол-во "читаемой" информации, те стоит избегать таких коды аэропортов(заменяем на имена аэропортов), id пассажиров(заменяем на ФИО) и тп.
* Если будет не хватать констант(например цена топлива на км) то возьмите какую-то реалистичную сами, можете загуглить, но явно опишите что принимаете такую константу.
* Допом могут понадобиться:
    * https://www.postgresql.org/docs/current/functions-conditional.html

### Задания:

1. Проведите анализ транзитных потоков пассажиров через различные аэропорты. Определите основные транзитные узлы (хабы), через которые проходит наибольшее количество пассажиров. Для каждого аэропорта рассчитайте соотношение транзитных пассажиров к общему пассажиропотоку и оцените потенциальное время стыковки.
2. Разработайте систему оптимизации распределения самолетов по маршрутам с учетом. Для каждого маршрута определите оптимальный тип самолета, сравнивая фактически используемый с рекомендуемым. Найдите рейсы, где выгодней всего было бы использовать другой самолет, но чтобы качество услуг не изменилось.
3. Проведите анализ предпочтений пассажиров времени бронирования билетов по дням недели и времени суток. Определите наиболее востребованные дни недели и часы. Найдите наиболее оптимальное время для бронирования относительно средней цены на рейс и учитывая класс бронирования.
4. Исследуйте соотношение цены и дальности полета для различных типов самолетов и классов обслуживания. Рассчитайте стоимость за километр полета для каждой комбинации модели самолета и класса. Определите наиболее экономичные варианты для пассажиров, а также наиболее выгодные комбинации для авиакомпании с точки зрения выручки.
